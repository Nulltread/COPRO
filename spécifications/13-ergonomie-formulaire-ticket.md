# Ergonomie de l'interface — décisions validées avec le demandeur

Ces règles d'interface s'appliquent à **tous les rôles** (résident, conseil syndical, admin).

## Formulaire de création d'un ticket

Ordre des champs, de haut en bas :

1. **Titre court** ;
2. **Urgence** (toggle « C'est urgent ») directement sous le titre ;
3. **Description** ;
4. **Zone d'ajout de photos** ;
5. **Sélection des villas / garages** (multiselect, en dernier, unités personnelles présélectionnées) ;
6. Bouton « Déclarer le ticket ».

## Zone d'ajout de photos (création et édition d'un ticket)

- **Zone encadrée** (bord arrondi, fond gris, bordure en pointillés) avec un **« + »** et un **logo photo**, située juste sous la description — comme sur les sites d'annonces. Le champ fichier lui-même est masqué.
- Le texte « compressées automatiquement avant l'envoi » n'est plus dans le libellé principal : il est en petit sous le texte d'invitation.
- **Une fois les photos ajoutées** : une **miniature** s'affiche par photo, chacune avec une petite **poubelle** pour la retirer de la sélection avant envoi.
- S'applique aussi au formulaire d'ajout de fichiers sur la page d'un ticket.

## Barre de navigation

- Le bouton de création de ticket est un **bouton encadré à bords arrondis, flat** (bordure, pas de fond blanc plein), avec le **texte visible « + Nouveau ticket »**.
- **Plus de lien « Rattachements » dans la barre de navigation** : les rattachements font partie de **l'écran de compte** (page « Mon profil », section « Mes rattachements » avec un lien vers la page des rattachements).
